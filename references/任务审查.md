# Longtask 审查

本页供主技能选择 review 模式后加载。复用[主技能](../SKILL.md)，按本次风险读取[专家审查协议](../专家审查协议.md)的独立性和结论要求。对照当前批准的目标、合同与验收检查成果，可在中途审查，不只对照最初架构；切换模式不构成审查独立性。

## 冻结被审对象

- **有检查点：** 校验 v3 状态及 review 帧的摘要、HEAD 和证据代际，用 `target`、`required_inputs` 与验收定位对象。
- **无检查点：** 对用户指定范围冻结当前摘要，不为只读审查制造任务档案。目标不明确时报告缺口，不猜测“上一步”或伪造批准。

按风险选择独立审查者，仅提供最小权威输入；使用子智能体须符合宿主能力与用户授权。执行与主张相关的确定性检查，按[审查收敛](../专家审查协议.md#审查收敛)综合根因、分歧及覆盖缺口，交付可核验结论。只有状态更新获授权时才写临时结构化证据。

## 结论与修复边界

仅审查请求保持代码和文档只读。失败 review evidence 生成包含 `check_id` 与 finding ID 的 `remediate` 交接。修复获授权后，保留原始发现、修复版本及独立复验证据，再用新摘要生成新 review 交接。

全部阻断项独立关闭、覆盖完整且审查摘要等于当前摘要，才可批准。必要结论按[知识合并与清理](../文档架构.md#知识合并与清理)进入项目知识，不形成长期已修复问题清单或审查日志。可选建议不延迟符合合同的交付。
