# Longtask 既有项目接入

本页供主技能选择 retrofit 模式后加载。复用[主技能](../SKILL.md)，已有实现但目标、结构或合同缺口妨碍后续工作时，按当前目标限定接入范围。单纯补写或整理已明确的文档用 continue。

读取相关入口、文档、代码和测试；只有合同或来源缺口才查历史，不先做全库盘点。

## 接入结果

从用户及持久来源恢复目标，以 `retrofit` 初始化 v3 检查点，按真实职责和依赖建立最小架构/模块合同。知识创建查[文档架构](../文档架构.md)，状态操作查[状态协议](../references/状态协议.md)相关章节。

区分并保留来源：代码/运行行为为版本绑定的 `observed`，未确认意图为 `inferred`，冲突为 `disputed`。已批准意图保持其权威，不用代码覆盖目标；目标确实改变时用 `goal` 协调。

验收、来源和文档缺口保持可见，无关改进不扩入范围，未经另行授权不重构代码。仅接入时按该范围验收并遵循[完成合同](../SKILL.md#变更与完成)；接入是整体实施的前置步骤时，继续原任务主线。
