# 评测体系

**最后更新：** 2026-10-09

## 职责

区分打包合规与技能实际质量，防止仅凭直觉接受提示词或工作流变化。

## 套件

| 套件 | 覆盖的声明 |
|---|---|
| `scripts/build_release.py` + `release-manifest.json` | 确定性发布闭包、逐文件摘要、工作区一致性和摘要约束提取 |
| `scripts/validate_longtask.py` | 静态一致性；`--installed` 校验提取后的闭包与嵌入清单；`--require-release-pass` 额外要求 Codex 宿主与当前版本恢复门通过 |
| `.github/workflows/ci.yml` | 单一 Python 3.14 任务：已保存绑定检查、单元测试、当前前向合同与源码校验；不执行发布 |
| `tests/` | 路由、任务安全、CAS 版本、摘要、审查新鲜度、事件日志、发布重现和完成门 |
| `evals/invocation_cases.json` + `invocation_results.json` | 应触发/不应触发、预期入口和与语料/发现面/runner 绑定的分类记录 |
| `evals/progress_cases.json` + `progress_results.json` + `scripts/run_progress_evals.py` | 原 Pi A–E 的八类源码显式推进旅程；保留采集、产物验证与独立语义观察的不同保证 |
| `evals/memory_cases.json` + `memory_results.json` + `scripts/run_memory_evals.py` | 代表性恢复任务的真实源码显式消费基线、组合与源码消融；独立线程及原采集/当前评分绑定 |
| `evals/forward_cases.json` + `forward_results.json` | 隔离的确定性状态 CLI 合同；不声称真实智能体行为 |
| `evals/host_results.json` + 独立前向审查 | 从确定性发布归档启动的全新 Codex 会话、真实技能加载、跨会话恢复、工具/交接 trace 和风险覆盖 |

文档引用按实际本地链接、锚点和模块入口结构校验；普通文字中的历史文件名不作为失效引用。归档提取后的链接闭包由安装自检回归覆盖，链接缺失和锚点错误由校验器负例覆盖。

Skill 校验覆盖格式与项目前置字段，六个入口的 UI 默认提示及隐式调用策略单独检查；所有入口 UI 文件进入调用发现面和前向合同输入绑定。字段的规范来源与项目约定见[仓库维护](../仓库维护.md#skill-格式与项目约定)。CI 先检查已保存结果再重跑确定性合同，避免自动更新掩盖过期证据。

跨 Python 版本的安全回归以结构化拒绝和状态不变为验收，不把一种底层错误措辞当作唯一合同。[Python pathlib 文档](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.resolve)说明 3.13 起非严格解析符号链接循环不再抛异常；状态运行时仍通过符号链接别名检查拒绝危险写集。循环路径测试覆盖这两种拒绝方式，并检查失败后工作包和 revision 未被写入。

跟踪路由/恢复准确率、过期/冲突检测、人类介入、返工、token、时间和成本。完整规范见[评测协议](../../references/评测协议.md)。

调用分类记录与真实宿主执行的保证级别分别保存，不能用分类满分替代真实技能激活。带 trace 的重复分类逐轮绑定身份、摘要和完整决策，评分包含全部轮次；原始 trace 真实性仍需独立核验。前向 runner 精确执行清单中的测试，数量不符、skip 或超时都会失败，并绑定全部合同输入。

宿主 schema v7 分离结构校验、核心发布资格与收益资格。样本能力适用性须说明证据；未知遥测不归零，调用计数必须自洽。真实trace和适用性判断由独立审查核验。源码运行结果不进入发布闭包，安装自检只验证随包合同与嵌入字节清单。具体字段与资格由[评测协议](../../references/评测协议.md)定义。

发布遍历遇到不可读子树会终止；归档输入拒绝 FIFO，避免恢复进程阻塞。完整合同和指标定义统一见[评测协议](../../references/评测协议.md)与[发布与恢复](../../references/发布与恢复.md)。

## 证据职责

当前版本的通过、失败与缺口仅保存在源码侧评测结果和临时检查点；本模块不复制易过期的候选状态。已执行的恢复子检查逐项登记，尚未执行的步骤保留未知。核心发布与收益判断分别报告。

## 宿主采集

`scripts/collect_host_trace.py` 将真实 App Server 传输写入受控外部存储，记录归档绑定、用量、压缩与审批事件；采集与评分分离，未知字段不填造。操作和保证边界见[评测协议](../../references/评测协议.md#真实宿主采集入口)。

核心推进、只规划边界、断点续接、主线偏移、分支出口、插入请求、明确改换目标、建议收敛和过期证据场景见[推进与收敛行为场景](../../references/评测协议.md#推进与收敛行为场景)。场景走查与实际宿主效果测量分开报告。

平行窗口的外部依赖到达、共享写集、真实链路缺口及独立恢复场景见[平行协作行为场景](../../references/评测协议.md#平行协作行为场景)。参考文件加入确定性前向结果的输入摘要；该绑定只能检测文本变化，不能替代实际协作行为评测。

## 指令负担与推进观测

`scripts/measure_skill_context.py` 只读对照目录并报告发现描述及调用方选择文件的字节/字符、摘要和声明引用。入口资料与实际 trace 路径可分别选择；导航闭包不自动计入读取量，不能从文件体积声称 token 或时间收益。口径与命令见[上下文负担测量](../../references/评测协议.md#上下文负担测量)。

`scripts/run_forward_evals.py --run` 执行当前合同且不写保存结果；`--write` 留给实际结果绑定者。清单通过 Python AST 对应真实测试类方法，注释中的方法文本不计覆盖。调用语料与邻近有界任务保持平衡；续接选择与只读检查的确定性测试只证明 CLI 合同，不证明模型正确使用已有授权。

首个有效推进、重复读取/检查、错误询问、完成范围与按需披露的宿主观测统一见[宿主推进对照口径](../../references/评测协议.md#宿主推进对照口径)。复用既有采集入口，缺失证据保留未知；格式、闭包与关键状态合同继续校验，措辞或固定步骤不升级为行为证明。

有界工作前沿、知识定向读取、关键调查中断、保存后恢复、环境变化、需求覆盖及收尾后的知识恢复见[记忆消费与恢复场景](../../references/评测协议.md#记忆消费与恢复场景)。接口测试与独立智能体消费评测分别提供确定性和行为证据；输出变小不能单独证明成功率、模型 token 或压缩频率改善。

实际记忆对照的采集、复算、私有复核与保证边界统一见[记忆基线与消融执行](../../references/评测协议.md#记忆基线与消融执行)。该结果属于源码侧外部评测，不随安装包分发；静态校验验证当前评分绑定与统计，不把结构校验当作行为通过。

原 Pi A–E 的当前职责与条件选择见[架构方向](../ARCHITECTURE.md#pi-优化方向)；采集、观测与收益的唯一口径见[推进旅程观察](../../references/评测协议.md#pi-推进旅程观察)。结果为源码侧验证输入，不随发布归档分发，也不改变完整宿主门。
