# 专家审查

**最后更新：** 2026-09-07

按不同故障模式选择独立审查者，保留分歧与证据，并阻止自我批准式关闭。

审查者选择、结果结构、严重级别、分歧与关闭统一见[专家审查协议](../../专家审查协议.md)。[`longtask-review`](../../skills/longtask-review/SKILL.md) 加载该合同；[状态运行时](状态运行时.md)把结果绑定到产物和工作包。[平台适配器](../../references/平台适配器.md)定义独立审查的宿主能力降级。

确定性用例验证逐包覆盖、发现关闭和证据过期；真实独立审查行为须由[宿主评测](../../references/评测协议.md)验证，不能从静态形状推断。

审查 envelope 的任务身份、证据代际、HEAD 和摘要在启动时冻结；提交者不得按提交时状态刷新绑定。权威字段和关闭条件见[专家审查协议](../../专家审查协议.md)。
